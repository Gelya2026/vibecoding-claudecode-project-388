# Скиллы проекта

Здесь живут скиллы Claude Code для трекера цен. Claude подхватывает их автоматически.

## Структура

Каждый скилл — отдельная папка с файлом `SKILL.md`:

```
.claude/skills/
└── <имя-скилла>/
    ├── SKILL.md        # обязательный: метаданные и инструкции
    ├── scripts/        # необязательно: вспомогательные скрипты
    └── references/     # необязательно: справочные материалы
```

## Шаблон `SKILL.md`

```markdown
---
name: имя-скилла
description: Что делает скилл и когда его вызывать (по этому тексту Claude решает, запускать ли скилл).
---

# Название скилла

Пошаговые инструкции для Claude.
```

Скилл можно вызвать вручную командой `/<имя-скилла>`.
